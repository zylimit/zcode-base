# verifier-must-poll-the-signal

- 日期: 2026-09-02
- 来源: cc 2df0e72 误诊修正（批次 1 研究增量报告）
- 信号: 信号在场没人接（红色通知挂一个月 / 回执状态可查但验收时未查）
- occurrence: 1

## 现象

- 红色通知（CI 失败/检查报错）持续在场一个月，无人响应。
- 回执/账本状态随时可查（receipt verify、gate-log），但验收动作里没有「查」这一步——证据躺在那，验收方看的是自报结果。

## 根因

不是闸不够响——加通知、加提醒是错误解法（信号已经在了）。真正缺口是验收方的验收流程没有把「主动查询既有信号」列为必做动作：信号推送 ≠ 信号消费。

## 规则

验收清单必须包含对既有信号的主动查询步（CI 状态 / 回执状态 / 警告计数），查询结果与被验收方自报并列核对。缺查询步的验收流程本身是缺陷——验收动作不完备时，「通过」只是转述。

## 执法建议

release 加 ci-status 条件（与 local-green-is-not-ci-green 同面）+ Stop 门播报强化：收尾播报点名「本次验收查询了哪些信号源、结果如何」（候选，批次 2 评估）。
