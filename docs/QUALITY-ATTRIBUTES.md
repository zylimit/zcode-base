# QUALITY-ATTRIBUTES — 五性治理深度定义

> 细则入口 `rules/quality-attributes.md`；本文是深度版：每属性的攻击面、设计手段、验证手段与常见反模式。

## 0. 总模型

```
模块 attributes 声明档位（module-catalog）
  + verification-matrix 认领检查（proves 属性）
  + 账本回执（四态 + fingerprint）
  → quality verify 反证优先 → task finish 阻断 blocking
  → fitness 审计接线（声明必有执法）
```

## 1. 韧性 Resilience

**口径**：遭受攻击、故障或自然灾害时，主动识别风险并快速恢复；抵抗大规模并发冲击。

| 手段 | 验证 |
|---|---|
| 超时+重试（指数退避+抖动） | 故障注入：依赖延迟/宕机时行为符合预期 |
| 熔断器（失败率触发，半开探针恢复） | 连续失败触发熔断的测试 |
| 降级路径（核心功能保命，边缘功能可关） | 依赖不可用时核心链路仍可用 |
| 过载保护（排队上限/限流/背压） | 压测超阈值返回受控错误而非雪崩 |
| 健康探针+自愈 | 探针失败触发重启/摘流 |

**反模式**：无限重试放大故障；重试无退避造成同步风暴；降级路径从未演练（=没有降级）。

## 2. 安全 Security（网络与信息安全）

**口径**：防范未授权访问、破坏、窃听或篡改；保障数据与信息安全。

| 手段 | 验证 |
|---|---|
| 认证鉴权全入口覆盖 | 未授权请求 401/403 矩阵测试 |
| 输入校验（注入/越界/类型） | 恶意输入语料测试（含模糊测试） |
| 密钥管理（环境变量/KMS，不入库不入日志） | secret-scan 零命中 |
| 传输加密+内部服务间信任最小化 | TLS 配置审计 |
| 依赖漏洞扫描+锁定 | lockfile 审计 + CVE 扫描 |

**红线**：security 永不可豁免、Fast Mode 永不跳过、hook 硬拦密钥读取（.env/*.key/id_rsa）。

## 3. 安全 Safety（功能安全）

**口径**：系统故障或失效时不对人类、物理环境或设备造成实质性伤害。

| 手段 | 验证 |
|---|---|
| 失效安全默认（fail-safe：断电/崩溃后进入安全态） | 断电/kill -9 后状态机回到安全态测试 |
| 危险操作联锁（双重确认/物理条件满足才可执行） | 联锁旁路尝试测试 |
| 越界钳制（物理参数限幅） | 边界值测试（超限被钳制不执行） |
| 失效告警（ watchdog 超时上报） | watchdog 超时触发告警测试 |

**定档提示**：工业控制/车载/医疗设备 critical 起步；纯软件工具通常 none+reason（失效不伤人，fail-visible 即可）。

## 4. 隐私 Privacy

**口径**：数据收集、使用、存储、销毁符合法规（GDPR/个保法）及隐私设计原则。

| 手段 | 验证 |
|---|---|
| 最小收集+用途限定 | 数据清单审计（DFX-Spec 必填） |
| PII 标记+脱敏（日志/导出/错误消息） | 日志抽样无 PII 明文 |
| 留存期限+自动销毁 | retention 策略执行证据 |
| 用户权利响应（访问/更正/删除/导出） | 权利请求流程演练 |
| 上下文包 DENY 路径 | context pack manifest denied 计数 |

**红线**：PII/密钥不入日志、不入上下文包、不进 git、不入 feedback 条目。

## 5. 可靠 Reliability

**口径**：规定条件和时间内，按预期持续、稳定、无故障执行业务。

| 手段 | 验证 |
|---|---|
| 单元/集成/回归测试金字塔 | 测试运行器真实输出 + exit code |
| 错误处理完备（无空 catch/吞错） | 静态审查 + 注错测试 |
| 幂等性（重试/重放安全） | 重复调用幂等测试 |
| 可观测性（结构化日志/指标/追踪） | 关键路径有指标告警 |
| SLO+错误预算 | SLO 达成率报表 |

## 6. 档位与豁免速查

| 档位 | 义务 | 豁免 |
|---|---|---|
| critical/high | matrix 认领检查 + 新鲜 PASS 回执 | security/safety 拒绝；其余五要素齐全可短期豁免 |
| medium/low | 建议认领；Fast Mode 可跳自动验证 | 常规豁免 |
| none | 必须 reason | — |
